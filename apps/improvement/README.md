# Improvement

Producto para el dueño de una empresa cliente y su equipo — objetivos con motor de puntos, escena 3D
del negocio, Mapa de Construcción, PowerUps, CRM ligero y sugerencias de IA.

Ver `CLAUDE.md` en la raíz del monorepo para comandos, arquitectura y convenciones. Desarrollo local:

```bash
pnpm dev:improvement   # http://localhost:3200
```

Desplegado en Vercel con Root Directory = `apps/improvement`.

Versión de Node requerida: ver `.nvmrc` en la raíz del monorepo.
